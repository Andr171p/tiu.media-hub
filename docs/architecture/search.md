# Поиск

| Запрос | Источники | Эндпоинт |
|---|---|---|
| Естественный язык («студент получает диплом на сцене») | CLIP text→image по кадрам + полнотекстовый поиск по названию, описанию, ИИ-описанию, тегам + речь | `POST /api/v1/search` |
| По фото (все ракурсы продукта) | CLIP image→image по кадрам фото и видео | `POST /api/v1/search/by-image` |
| По селфи | Лица (SFace) | `POST /api/v1/search/by-face` |
| Человек | Подписанные и распознанные лица текущих версий | `GET /api/v1/assets?personId=…` |

Результаты содержат `matches`: источник совпадения (`visual`, `text`, `speech`, `face`) и `timecode` —
момент в видео, к которому плеер может перейти.

## Модели

* **CLIP** в Infinity: изображения — `openai/clip-vit-base-patch32`, текст —
  `sentence-transformers/clip-ViT-B-32-multilingual-v1` (то же пространство, понимает русский). 512 измерений.
* **Лица**: OpenCV YuNet (детектор) + SFace (векторы, 128 измерений). Лицензии Apache-2.0/MIT, быстро на CPU.
* **Описание и теги**: VLM через OpenAI-совместимый API — `gemini-2.5-flash-lite` через AITunnel в разработке,
  `qwen3-vl:4b` в Ollama на сервере.
* **Речь**: faster-whisper (`base` на CPU, `small` на GPU), русский язык.

## Индексы

* Qdrant `dam_visual`: точка на кадр версии (изображение — один кадр, видео — до 24), payload:
  `asset_id`, `version_id`, `collection_id`, `kind`, `timecode`, `current`, `trashed`.
* Qdrant `dam_faces`: точка на лицо, payload + `person_id`, `confirmed`.
* PostgreSQL: `assets.search_vector` (generated, русская морфология, веса: название и теги — A,
  описания — B) и `transcripts.search_vector`.

Точки хранятся для всех версий; в поиск попадают только `current=true`, `trashed=false` из доступных
коллекций. Перенос, корзина и смена текущей версии меняют payload (`ai.sync_asset`) без переиндексации.

## Ранжирование

Источники объединяются через Reciprocal Rank Fusion (`k=60`). Кадры одного актива сворачиваются
в один результат. Визуальные совпадения весят меньше (`0.5`): у CLIP ViT-B/32 релевантный текст даёт
сходство ~0.25, а шум — до ~0.21, тогда как совпадение в описании ИИ или речи почти всегда точное.

Пороги — свойство модели (настраиваются в `.env`): `INFINITY_TEXT_MATCH_SCORE=0.21`,
`INFINITY_IMAGE_MATCH_SCORE=0.75`, `FACES_SAME_PERSON_SCORE=0.42`.
При смене модели CLIP пороги нужно подобрать заново, а коллекцию `dam_visual` пересоздать.

## Распознавание людей

1. После обработки найденные лица сравниваются с уже подписанными: при сходстве ≥ порога лицо
   получает человека автоматически (`confirmed=false`).
2. Подпись лица вручную (`PUT /faces/{id}/person`) запускает фоновое распознавание этого человека
   на всех неподписанных лицах.
3. Ручная подпись имеет приоритет: автоматика её не перезаписывает.
4. В видео появления одного человека склеиваются в одно лицо с таймкодами.
