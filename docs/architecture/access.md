# Доступ

**Keycloak отвечает только за личность**: кто пользователь и есть ли у него глобальная роль `admin`.
Права на коллекции, порталы и подборки хранит и проверяет бэкенд.

## Аутентификация

* Токен проверяет DDF `KeycloakTokenVerifier`: подпись (JWKS с кешем), `iss`, `aud=tiu-media-hub-api`,
  `exp`, `typ=Bearer`.
* `infra/auth.py` превращает claims в `Auth`:
  * `azp` из `KEYCLOAK_SERVICE_CLIENT_IDS` — сервис (Client Credentials);
  * `azp` из `KEYCLOAK_USER_CLIENT_IDS` — пользователь (`sub`, имя, email);
  * роли — только `resource_access["tiu-media-hub-api"].roles`.
* Ошибки: нет/неверный токен — 401, Keycloak недоступен — 503, недостаточно прав — 403.

## Клиенты realm `tiu-media-hub`

| Клиент | Назначение |
|---|---|
| `tiu-media-hub-web` | SPA: Authorization Code + PKCE |
| `tiu-media-hub-api` | Resource server: аудитория и роли `admin`, `assets:read` |
| `tiu-media-hub-service` | Сервисы (Client Credentials), роль `assets:read` → `/api/service/v1` |
| `tiu-media-hub-dev` | **Только разработка**: password grant для curl и тестов. Удалить в production |

## Права на коллекции

| | read | write | manage | own |
|---|---|---|---|---|
| Владелец, администратор | ✓ | ✓ | ✓ | ✓ |
| `manager` | ✓ | ✓ | ✓ | |
| `editor` | ✓ | ✓ | | |
| `viewer` | ✓ | | | |
| Любой сотрудник, если коллекция `internal` | ✓ | | | |

* `read` — просмотр, скачивание, комментарии; `write` — загрузка и правка активов, подпись лиц, редактор;
  `manage` — участники, настройки, удаление из корзины, удаление чужих комментариев; `own` — удаление коллекции.
* Нет права чтения — ресурс «не существует» (404), чтобы не раскрывать его наличие.
* Списки и поиск фильтруются по доступным коллекциям прямо в SQL и Qdrant.

## Прочие ресурсы

* **Подборка**: владелец (и администратор) меняет; `shared` — читают все. Активы показываются только
  из доступных коллекций.
* **Портал**: управляет владелец (и администратор). Сохранить источник в портал может только тот,
  кто сам его читает. Посетители: `public` — все, `password` — токен из `/unlock` в `X-Portal-Token`,
  `employees` — любой вошедший сотрудник.
* **Справочник людей**: читают и пополняют все сотрудники; меняет и удаляет автор или администратор.
